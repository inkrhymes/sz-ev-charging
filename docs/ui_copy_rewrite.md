## 语气原则

1. 能说「站」就不说「站点」；能说「缺数」就不说「缺失率」。
2. 表头用短词（说明、结论、问题），解释放到卡片副文案或 tip。
3. 不要出现 TAZ、stub、naive、MOCK、LIVE、row_missing_rate 等开发词。
4. 百分比口语可写成「三成」「一半」，正式数字仍显示 `26.42%`。
