# 演示子集站点清单（已锁定，25 站）

对齐：`docs/demo_subset_rules.txt`、`data/demo/demo_station_ids.txt`、`data/demo/demo_station_list.csv`  
数据源：UrbanEV `20220901-20230228_station-raw/charge_5min/{station_id}.csv`  
时间窗（ETL 默认切片）：**2022-09-01 ～ 2022-09-14**（14 天 × 5 分钟），清洗规则与全量一致。  
负责人：小紫（造数/子集 ETL）；列表由小黑/既有选取规则固化，**禁止另造站号**。

## 选取规则（答辩口径）

1. 从 UrbanEV 原始 station-raw 中选取 **20～30** 个真实站点（本子集锁定 **25**）。
2. 必须包含：至少 **2** 个占用数长期不变的**卡死站**、至少 **3** 个缺失率 **>30%** 的站、其余为正常站。
3. 覆盖忙闲片区：TAZ 分散（宝安/南山/福田/龙岗等方向均有坐标），含大站（如 1566 共 63 桩）与小站。
4. 时间范围与全量一致可选；演示 ETL 为控制体积切片 14 天，质检口径不变。
5. 清洗、聚合、工单建议规则与全量相同；仅缩小站点集合以便 1～2 分钟跑通。
