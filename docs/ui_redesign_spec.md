# 前端设计系统规范：「绿牌 · 电量格」深圳充电站调度台

适用文件：`web/index.html`（单文件纯 HTML / CSS / 原生 JS + ECharts 5.5.1 + Google Fonts Barlow Semi Condensed，无前端框架与构建步骤）。

---

## 1. 设计方向与视觉锚点

全站仅在三处发力，其余区域保持低噪、平整、信息密度清晰的调度值班台气质：

1. **新能源绿牌**：深圳街头最常见的电车视觉符号。决定主色 `--plate (#0A7D4F)` 与品牌标——一枚 `30×20px` 双色拼接「粤B」迷你号牌（左 40% `--plate` 底白字「粤」+ 右 60% 纯白底 `--plate` 字「B」，1px 绿框，3px 圆角，无渐变）。
2. **电量格组件（`cellMeter`）**：充电桩与车机上的分段电量条，是全站唯一的视觉记忆点，统一用于表示「占用率」（总览主读数、实时页横向分段排行与全站表格占用率列）。
3. **调度值班台**：读数有气场、色彩只服务数据、卡片零阴影、无渐变、无毛玻璃、无发光霓虹、无 999px 胶囊、无 emoji、浅色单主题。

### 2.1 占用率固定刻度 `occColor(v)`

地图、电量格、实时排行与所有表格统一调用 `occColor(v)`：

| 区间 | 色值 | 说明 |
|---|---|---|
| `0% – <20%` | `#DDEFE5` | 极低占用（白底配 `#B8DEC9` / `#8CC5A8` 细边防融合） |
| `20% – <40%` | `#A6D7BC` | 较空 |
| `40% – <60%` | `#5DB98A` | 适中 |
| `60% – <75%` | `#1F9562` | 偏忙 |
| `75% – <90%` | `#0A7D4F` | 繁忙 |
| `≥ 90%` | `#B45309` | 排满（读数同步切琥珀色） |
| 无数据 | `#E3E7E5`（空心） | 地图空心灰圈；电量格全空心描边并显示「暂无」 |

### 2.2 ECharts 主题（`szPlate`）

- 统一通过 `echarts.registerTheme("szPlate", ...)` 注册。
- 调色板：`['#0A7D4F', '#56677A', '#C98A1B', '#2F6FB0', '#B4233C', '#9AA6A0']`。
- 面积填充仅使用主色 8% 透明度纯色 `rgba(10,125,79,0.08)`；误差柱使用 `rgba(201,138,27,0.60)`；全站禁止 `LinearGradient` 与 `shadowBlur`。

## 3. 字体栈、字号阶梯与圆角层次

- **中文与正文栈**：`"PingFang SC", "HarmonyOS Sans SC", "MiSans", "Microsoft YaHei", system-ui, sans-serif`。
- **仪表读数栈**：Google Fonts `Barlow Semi Condensed`（500 / 600）+ `font-feature-settings: "tnum" 1`（Chromium 实测 `111` 与 `888` 渲染宽度严格等宽：`54.765625px`），仅用于 KPI 数值、电量格百分比与时间读数（如 `18:00`、`23:55–00:10`、工单处理用时）。

| 层级 | 字号 / 行高 | 字重 | 字体 |
|---|---|---|---|
| 总览主读数（平均占用率） | `56px / 60px` | `600` | Barlow Semi Condensed |
| KPI 数值 | `36px / 40px` | `600` | Barlow Semi Condensed（单位 `13px` 正文栈 `--ink-3`） |
| 页面标题 | `24px / 32px` | `600` | 系统中文栈 |
| 卡片标题 | `15px / 22px` | `600` | 系统中文栈 |
| 正文 / 表格内容 | `14px / 22px` | `400` | 系统中文栈 |
| 辅助文字 / 表头 / 侧栏分组 | `12px / 18px` | `400`（表头 `600`） | 系统中文栈 |

- **圆角分层**：卡片 `8px` ｜ 按钮/输入框/菜单项 `6px` ｜ Tag `4px` ｜ 品牌号牌 `3px` ｜ 电量格单元 `1.5px`。
- **间距基准**：4px 网格；内容区左右 `24px`；卡片间距 `16px`；表格表头 `#F6F8F7`、行高 `44px`、仅横线、数字列右对齐、悬停行 `#F6F8F7`。

## 4. 电量格组件 `cellMeter(v, opts)` 规范

- **签名**：`cellMeter(v, { cells = 10, size = 'md', showVal = true, animate = false, label = '占用率' })`。
- **尺寸**：
  - `md`（总览主读数下方）：10 格，每格 `6×14px`，格间距 `2px`，圆角 `1.5px`。
  - `sm`（全站表格占用率列与待关注站缺数比例列）：10 格，每格 `4×10px`，格间距 `2px`，圆角 `1.5px`。
  - 末端固定配备 `2×6px` 电池正极凸起（`#C9D1CD`）。
- **状态与语义**：
  - 点亮格数 `Math.round(v * 10)`，填充色取自 `occColor(v)`；未点亮格 `#E9EDEB`。
  - 无数据时全部 10 格空心描边，数值显示「暂无」。
  - 容器标注 `role="meter"`、`aria-valuemin="0"`、`aria-valuemax="100"`、`aria-valuenow` 与 `aria-valuetext`。
- **唯一自动动效**：总览首次加载时，主读数下方电量格从左到右逐格点亮一次（每格间隔 `25ms`，总时长 `345ms ≤ 400ms`）；在 `prefers-reduced-motion: reduce` 下直接展示最终态。其余交互仅保留 `120–150ms` 悬停与展开过渡。

## 5. 页面骨架与逐页要点

- **外壳**：顶栏高 `56px` 白底，左「粤B」号牌 + 系统名，右纯文字「数据时间 | 数据源 | 刷新 | 用户」（1px 竖线分隔，无胶囊边框）。侧栏宽 `220px` 白底（折叠宽 `56px`），4 个分组标题 `12px --ink-3` 常规字重，菜单项高 `36px`，选中态 `--plate-tint` 底、`--plate-strong` 字、`--plate` 图标（无左竖条与阴影）。移动端 `≤700px` 切换为 `#mobileRoute` 下拉选择。
- **运行总览（`overview`）**：顶部一体式「城市读数」横幅（通过 CSS `grid-area` 将 DOM 第 3 项平均占用率放于左侧主读数区：56px Barlow + `md` 电量格 + 峰值时段，右侧 5 列 1px 竖线分隔，严格保留 `#kpis .kpi-val` 下标顺序）；主图占 16 栏（主色细线 + 8% 纯色填充 + 琥珀虚线 `偏忙 75%`）；工单概况占 8 栏（单条 3 段状态堆叠条 + 3 行可点击按钮，无柱状图）；待关注站表格使用 Tag 与 `sm` 电量格。
- **实时占用（`realtime`）**：顶部 4 指标带（数据延迟 >60s 切琥珀色）；「最忙的 20 个片区」改为横向 ECharts `pictorialBar` 分段电量格排行（左片区名、中 `occColor` 电量格、右 Barlow 百分比）；明细表使用 `sm` 电量格。
- **片区地图（`map`）**：扁平深圳九区底图配 `#EEF1EF` 淡网格、等比锁定 `aspectScale: 0.923`，无经纬度轴标题与刻度；气泡颜色按 `occColor`、大小表示站点数、无数据画空心灰圈；时间轴为一体化播放器（播放按钮 + 24 段小格轨道滑杆 + Barlow 读数）；底部横向 6 段刻度图例（`0% … 90%+ 排满`）。
- **片区分析 / 和上小时比（`zone` / `baseline`）**：实际值主色实线、上一小时对照与预测用 `--slate` 虚线、误差柱 `#C98A1B` 60% 透明度、白底多序列 Tooltip。
- **异常告警（`alerts`）**：重排为 8 列（编号不折行｜对象与次行片区｜问题｜情况占最宽并 2 行截断可悬停/点击展开｜紧急程度｜日期/时刻两行时间｜状态红/琥珀/灰 Tag｜操作列未登录仅显灰色 `—`，说明收敛于表头 `操作 ⓘ`）。
- **运维工单（`tickets`）**：处理用时改为单条横排 Barlow 读数；保留 5 步 `.flow .st`（已完成 `--plate`、当前实心加外圈、未到空心灰圈）。
- **数据关系（`lineage`）**：六列节点按层使用 `--plate`、`--slate` 与灰阶深浅（去彩虹色），默认视图无任何英文字母。
- **数据质量 / 调度运行 / 选址补桩 / 错峰预警 / 操作日志**：统一应用新 Token、无阴影卡片、44px 表格、`4px` Tag、Barlow 读数与 `sm` 电量格；移除了与电量格竞争的次级进度条与彩色排名框。

## 6. 无障碍与质量门禁

- 对比度：所有正文、主色与语义色在对应底色上满足 WCAG AA `≥ 4.5:1`。
- 键盘操作：`:focus-visible` 统一 `2px solid var(--plate)` 外描边偏移 `2px`；导航、Tabs、分页、侧栏折叠、用户菜单与弹窗均支持键盘完整操作。
- 禁用词与洁癖检查：页面可见文案与 Tooltip 禁绝「口径、基线、窗口、血缘、stub、（无）、undefined、NaN、[object Object]」及英文状态值；静态扫描 `grep -nE "gradient|backdrop-filter|#0b1220|IBM Plex|stub|naive" web/index.html` 输出为空。
- 视口兼容：`1280×800`、`1440×900`、`1920×1080` 与 `390×844` 全路由零横向滚动条，控制台零报错，除 `GET`/`OPTIONS`/`HEAD` 外不主动发出写请求。
