## 4. 说明

- 卡死判定：窗口内非缺失 `busy` 唯一取值（nunique==1 且有效点≥12）。
- 整行缺失：`busy` 与 `idle` 同时为空。
- 异常：按站对 `busy` 做 1.5×IQR；不删除行，仅打 `is_outlier`。
