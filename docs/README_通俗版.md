# 这个项目是干什么的（通俗版）

给你自己看的说明，仓库主页请用根目录正式版 `README.md`。

## 一句话

把深圳充电站的公开运行数据，做成「能清洗、能看数、能开网页大屏」的小系统，方便毕设答辩和投简历（比如字节）时讲清楚你做了什么。

## 系统大概怎么走

1. 从 UrbanEV 里挑 **25 个站**（故意包含坏站、缺数站）
2. 用脚本清洗，算出缺失率、卡死站等数字
3. 放进 MySQL 的三层表：原始层 → 明细层 → 指标层
4. Flask 提供接口，网页用 ECharts 画大屏
5. 顺带有一个简单工单列表、只读登录、上一时刻预测基线（都是轻量演示，不是完整大系统）

## 你要记住的硬数字（面试常问）

- 25 个站，14 天窗口，大约 10 万行
- 整行缺失率 **26.42%**
- 卡死站 **4**，高缺失站 **6**
- 仓库：https://github.com/inkrhymes/sz-ev-charging

## 你怎么自己跑起来

电脑要装 Docker。然后：

```bash
git clone https://github.com/inkrhymes/sz-ev-charging.git
cd sz-ev-charging
cp .env.example .env
bash scripts/start.sh
```

跑完后：

- 接口：浏览器打开 http://localhost:5000/api/health
- 大屏：打开文件夹里的 `web/index.html`

不想起数据库时，也可以只跑接口读本地 CSV：

```bash
cd api
pip install -r requirements.txt
python app.py
```

## 和开题报告的关系

开题题目是：**基于大数据技术的深圳市电动汽车充电站运行管理可视化系统设计与实现**

这个仓库是开题的「半个月能演示」版本：六大模块都有一点皮，但全量数据、真 LSTM、完整权限等留给后面毕设长线再做。
