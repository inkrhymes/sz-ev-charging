# 简历项目描述

**深圳市电动汽车充电站运行管理可视化系统**｜个人项目｜Python / Flask / MySQL / ECharts  
仓库：https://github.com/inkrhymes/sz-ev-charging

- 基于公开数据集 UrbanEV（深圳充电站 5 分钟运行数据），选取 25 个站点、约 10 万条记录作演示子集（覆盖 23 个片区，其中 18 个有完整曲线），搭建 ods → dwd → ads 三层数据链路，完成采集、清洗、分析到可视化的全流程。
- 编写数据质量检查脚本，识别读数异常与缺数偏多站点（缺数比例 26.42%，读数异常 4 站，缺数偏多 6 站），自动生成巡检 / 维修工单建议并输出检查报告。
- 用 Flask 提供 REST 接口，前端按企业后台风格实现运行总览、片区分析、对照预测、数据质量、运维工单五个页面（ECharts + 原生页面），支持筛选、分页与角色权限。
- 用 Docker Compose 编排 MySQL 与接口服务，一键脚本完成建表、装载、指标回填和启动；新环境克隆后可复现，34 项验收全部通过。
